# Minkowski GJK Analyzer

볼록다각형 두 개가 겹치는지를 GJK 알고리즘으로 판정하고, 그 과정을 단계별로 그려 보여주는 도구입니다.

- 데모: https://startling-crepe-5723ba.netlify.app/

## 소개

충남삼성고 2학년 기하 교과 탐구에서 만들었습니다. 정식 제목은
「길버트 존슨 키어시(GJK) 알고리즘의 민코프스키 차 기반 충돌 판정 분석」입니다.

두 볼록집합 A, B가 겹칠 조건은 민코프스키 차 A ⊖ B가 원점을 포함하는 것과 같습니다.
GJK는 이 성질을 이용해 차집합 전체를 만들지 않고, 심플렉스를 갱신하며 원점을 감싸는지만 봅니다.

## 주요 기능

- 두 다각형과 그 민코프스키 차를 화면에 표시
- 심플렉스가 갱신되는 과정을 단계별로 시각화
- SAT(분리축 정리)와의 반복 횟수·시간 비교

## 기술

바닐라 JavaScript. 빌드 과정 없는 정적 웹앱입니다.

| 파일 | 내용 |
|---|---|
| `gjk.js` | GJK 본체. 서포트 함수와 심플렉스 갱신 |
| `sat.js` | 비교용 분리축 정리 구현 |
| `shapes.js` | 정다각형 생성 |
| `main.js` | 화면·상호작용 |

## 실행 방법

```bash
open index.html
# 또는
python3 -m http.server
```

## 알아 둘 것

탐구 보고서는 SAT의 복잡도를 O(n)으로 결론지었는데, 같은 보고서의 실측 시간은 O(n²)을 가리킵니다.
축 개수가 28.7배일 때 시간은 476.9배였고, 구간별 실측 지수가 1.76 → 1.89 → 1.93 → 1.96으로 2에 수렴합니다.
축마다 모든 꼭짓점을 투영하므로 총 비용이 O(n²)이 되는 것이 맞습니다.

"평균 1.5회 내 수렴"이라는 측정값도 정3~정100각형 12가지에서 전부 정확히 1.50이라,
반복 시행의 평균이 아니라 충돌 1회 + 비충돌 2회의 산술평균으로 보입니다. GJK는 결정적이라 같은 입력에서 횟수가 변하지 않습니다.
